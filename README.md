One star, written in sap: the old maple rates this park one star - sticky seats, no shade policy, and every autumn it dumps its leaves on my head and calls it ambiance.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```

The line is written to `/output/entry.txt` on every run, byte for byte the same.
